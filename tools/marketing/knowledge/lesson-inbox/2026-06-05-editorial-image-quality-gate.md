# Lesson Proposal: Editorial Image Quality Gate

## Proposed Durable Lessons

- Treat weak marketing images as an art-direction and QA failure before blaming the image model.
- Use reference images only to extract design principles: hierarchy, palette discipline, negative space, photo crops, and composition rhythm.
- Generate multiple candidates for each social image and reject outputs that fail the editorial quality gate.
- Keep final image copy short and public-facing; move strategy notes, dates, and review warnings into reports and captions.
- Use OpenAI for campaign/event/background visuals, but keep Bonhomia logos, suite photos, and public text as deterministic locked layers.

## Why This Matters

The first Bonhomia image run produced assets that looked like rough layout drafts. The next iteration should build a stronger habit: define the design system, produce candidates, review them with a vision-capable model, reject amateur outputs, and keep the reasons visible so Codex learns from the run.
