# Lesson Proposal: Professional Reference Image Pass

## Context

The first image-generation upgrade improved QA, but the business direct-booking asset still failed because the layout forced a factual suite photo into a claim that did not need a room. The result looked like a template draft: dark text card, tacked-on logo, disconnected photo, and weak editorial rhythm.

## Proposed Durable Lessons

- Do not force suite imagery into generic business/direct-booking ads. Use a brand-led poster when no suite is named.
- Financial underperformance can suggest strategic focus, but final creative must still choose photos based on visual quality and factual fit.
- The generator should use OpenAI for campaign atmosphere and hero visuals, then use deterministic composition for final type, CTA, logo, and suite-photo modules.
- Reference images should influence hierarchy, negative space, palette contrast, crop discipline, and grid logic, not exact layout or brand imitation.
- A candidate can have good copy and still fail if the layout reads as a generic text-card draft.

## Evidence To Review

- Previous failed business candidates were rejected for generic dark text-card treatment, floating/disconnected logo badge, weak suite-photo fit, and amateur layout.
- The new business treatment defaults to `business_brand_poster` when no suite is named.
- The new docs capture external rules for visual hierarchy, mobile creative, Swiss/grid discipline, and single-focal-point composition.

Review and promote the lessons that should become permanent rules.
