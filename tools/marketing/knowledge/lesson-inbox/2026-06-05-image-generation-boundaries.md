# Lesson Proposal: Image Generation Boundaries

Date: 2026-06-05
Brand: Bonhomia Suites

## Proposed Lessons

- Image generation does not always need suite photos; logo-only assets are valid when the strategy is brand, destination, awareness, or event focused.
- OpenAI may create visuals around Bonhomia suite imagery, but not inside the factual suite photo module.
- A local event image can feature generated event artwork and separately recommend a real suite as an ideal stay option.
- Real suite photos must not be altered in ways that imply amenities, objects, views, decorations, furniture, or layouts that do not exist.
- Each media run should write lesson proposals and tool notes so Codex keeps learning instead of relying only on chat context.
